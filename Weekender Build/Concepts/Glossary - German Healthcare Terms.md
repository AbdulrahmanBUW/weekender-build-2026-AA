# Glossary — German healthcare & phone terms

Use these in the agent prompt and in the English UI tooltips.

| German | English | Note for the agent |
|---|---|---|
| Arztpraxis / Praxis | doctor's practice | |
| Hausarzt / Hausärztin | GP / family doctor | first stop; often phone-only |
| Facharzt | specialist | often needs Überweisung |
| Termin vereinbaren | make an appointment | |
| Erstuntersuchung | first examination | default reason — no symptoms needed |
| Vorsorgeuntersuchung | check-up | |
| Akuttermin / Akutsprechstunde | urgent / same-day slot | |
| Neupatient(in) | new patient | practices may refuse → outcome `rejected_no_new_patients` |
| Versichertenkarte / eGK | health insurance card | "bring" item |
| gesetzlich versichert (GKV) | public insurance | e.g. TK, AOK, Barmer |
| privat versichert (PKV) | private insurance | |
| Überweisung | referral | ask: "Haben Sie eine Überweisung?" |
| Vermittlungscode | referral code for 116117 | out of scope |
| 116117 Terminservice | national appointment service | out of scope for MVP |
| Sprechzeiten | opening/consultation hours | |
| Telefonzeiten | phone hours | narrow windows |
| Wartezimmer | waiting room | |
| U-Untersuchung | child check-up (U1–U9) | persona Amina, v2 |
| Buchstabieralphabet | spelling alphabet | "S wie Siegfried" (DIN 5009) |
| Drücken Sie die 1 | press 1 | phone menu → DTMF |
| Richtig / Genau | correct | read-back confirmation |
| KI-Assistentin | AI assistant (female) | disclosure word |
