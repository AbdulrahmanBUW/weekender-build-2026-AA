# Voice Platform Comparison

**Definition:** which engine runs the German phone conversation (STT → LLM → TTS + telephony).
**Why it matters for us:** it decides how much custom code we write, whether the live transcript works, and whether we can ring a German mobile this weekend.
**Related:** [[Voice Pipeline - Architecture]] · [[DEC-001 Voice platform (proposed)]] · [[Telephony Constraints (Twilio Trial, Numbers)]] · [[Relay Hosting Options]] · [[Voice Risks and Mitigations]]

Researched 25 Sep 2026. "Unverified" = read in docs/reviews but not tested by us.

## Main table

## One-line summary
Pick a **managed platform** — Retell first, ElevenLabs as fallback — and spend the saved 10+ hours on the German prompt, the read-back and the UI. DIY Deepgram is the "production/EU" story for the pitch, not the weekend build.
