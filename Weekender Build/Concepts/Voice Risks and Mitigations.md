# Voice Risks and Mitigations

**Definition:** what can break the call or the demo, and what we do about it.
**Why it matters for us:** the live call is 80% of the demo's impact and 80% of its risk.
**Related:** [[Voice Pipeline - Architecture]] · [[DEC-001 Voice platform (proposed)]] · [[Telephony Constraints (Twilio Trial, Numbers)]] · [[AI Disclosure]] · [[Moment of Truth - First 15 Seconds]]

| # | Risk | Likelihood / impact | Mitigation | Rule |
|---|---|---|---|---|
| 1 | **The phone doesn't ring** (trial limits, geo permissions, Retell number can't dial +49) | High / fatal | Test Friday night; upgrade Twilio + enable Germany geo permission; fallback to browser web call; backup video. See [[Telephony Constraints (Twilio Trial, Numbers)]]. | — |
| 2 | **Live transcript doesn't reach the UI** | Medium / high (it's the "wow" for non-German jurors) | Retell `transcript_updated` → Edge Function → `transcript_lines` → Realtime. ElevenLabs has no live transcript for phone calls outside Enterprise ([docs](https://elevenlabs.io/docs/eleven-agents/guides/realtime-monitoring)) → show status steps from tool calls, full transcript after the call. Edge Function must dedupe (Retell sends the full transcript each time; insert only new indices). | — |
| 3 | **Latency / awkward turn-taking** (receptionist talks over the bot, long pauses) | Medium / high | Use a fast LLM tier (e.g. Claude Haiku/Sonnet-class, Gemini Flash); keep tool webhooks < 1–2 s (n8n "Respond to Webhook" immediately, heavy work after); enable barge-in / interruption sensitivity; short German sentences in the prompt; filler line "Einen Moment, ich prüfe kurz den Kalender." before tool calls. | — |
| 4 | **German STT on 8 kHz phone audio** (fast speech, Saxon accent, names, dates) | Medium / medium | Add keyterms / boosted words (`Überweisung`, `Versichertenkarte`, `Neupatientin`, doctor's name); make the agent **read back** date and time and wait for "Ja"; spell names with the German spelling alphabet; test with the teammate's real accent 10+ times. Deepgram: `keyterms` in `agent.listen.provider`. | [[Read-back before booking]] |
| 5 | **Booking outside allowed windows / hallucinated confirmation** | Medium / high | `check_slot` tool enforces windows in n8n code; `confirm_booking` only after read-back (Deepgram: `defer_until_eot: true`); outcome comes from the tool call, not from the LLM's summary. | [[Only book inside pre-approved windows]] |
| 6 | **Phone menu (IVR / DTMF)** "Drücken Sie 1 für Termine" | Low in demo / high in reality | Platform DTMF: ElevenLabs system tool `play_keypad_touch_tone` (digits, `w` = 0.5 s pause) ([docs](https://elevenlabs.io/docs/agents-platform/customization/tools/system-tools)); Retell has a press-digit option (unverified exact name); Twilio `sendDigits` for DIY. Demo: optional curveball, script the menu in German. | — |
| 7 | **Voicemail / Anrufbeantworter** ("Die Praxis ist zurzeit geschlossen…") | Medium in reality | ElevenLabs voicemail-detection system tool ([docs](https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/voicemail-detection)); Retell voicemail detection (setting name unverified); DIY: Twilio async AMD (`/amd-result` in the reference repo). Policy: **leave no message** (no health data on tape), mark outcome `no_answer`, retry later. | [[Data minimisation - no symptoms]] |
| 8 | **Receptionist hangs up / refuses to talk to a bot / wants the patient** | Medium | Disclosure framed politely and human ("…sie spricht leider noch kein Deutsch…"); `needs_user` tool → offer callback number; outcome `rejected_*`. | [[Never impersonate the user]] |
| 9 | **AI disclosure (EU AI Act Art. 50)** missing or late | Low if designed in / legal | Put the disclosure in the platform's fixed **first message / greeting** field (not left to the LLM): *"Guten Tag, hier spricht die KI-Assistentin von Frau …"*. Retell/ElevenLabs/Deepgram all have a static greeting. | [[AI discloses itself in first sentence]] |
| 10 | **Audio recording (§201 StGB)** — platforms record by default for their logs | Medium / legal | Turn off: ElevenLabs `call_recording_enabled: false` in the outbound request + disable audio retention / `post_call_audio` webhook; Retell: disable recording/storage in agent settings (exact toggle unverified; check "opt out of data storage"); Twilio: no `record` param; Deepgram: `mip_opt_out: true`. Store text only; ask consent to take notes. | [[Never store call audio]] |
| 11 | **GDPR / data in the US** (Retell no EU hosting; ElevenLabs EU = Enterprise) | Certain / low for demo with fake data | Demo with fake persona data only; pitch the production path: Deepgram EU endpoint + EU telephony + DPAs. | [[Data minimisation - no symptoms]] |
| 12 | **Free credit runs out mid-testing** | Medium | Retell $10 ≈ 40–50 min to Germany; ElevenLabs free = 15 min. Budget ~€20–30 per platform; one person owns the billing dashboards. | — |
| 13 | **Venue Wi-Fi / laptop dies** | Medium | Managed platform runs in the cloud — the call works even if the presenter laptop drops; use phone hotspot for the UI; backup video. | [[Deadline - live by Sunday 14h]] |
| 14 | **n8n Cloud execution limits / slow webhooks** | Low–medium | Don't send every transcript turn through n8n — send it straight to a Supabase Edge Function; n8n handles only tool calls + call end. | — |
