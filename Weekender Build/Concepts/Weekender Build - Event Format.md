# Weekender Build — Event Format

**Definition:** Three-day build event in Dresden (25–27.09.2026) by digitalwert (Daniel Dietze, n8n ambassador) and Bernhard de Luca (Lovable ambassador, UDANSA). "Not a hackathon, not a workshop, not a conference." Everyone builds their own project with Lovable + n8n + Supabase + Claude.

**Why it matters for us:** The only yardstick is: *live under its own URL, Sunday 27.09, 14:00, built by our own hands.* See [[Deadline - live by Sunday 14h]].

## Sunday target (quoted structure from the site)
1. A running build under its own URL — Lovable deploys automatically.
2. An automation workflow in n8n that moves data or tasks.
3. Optional: at least one AI function — understand, structure, decide text.
4. A demo that shows the project live (format decided on site).
5. A Monday-morning plan: what's needed to turn the build into something real → [[Monday-Morning Plan]].

## Schedule
| Day | Key slots |
|---|---|
| Fri 25.09 · Idea Day 16–22 | 17:00 Service-design input · 17:45 idea pitches (90 s) · 18:30 pod assignment · **20:00 Pod #01 Kick-off** · 22:00 commit |
| Sat 26.09 · Build Day 09–open | 09:30 Lovable deep-dive · 10:30 Build 1 · **13:00 Pod #02 Build-Check** · 17:00 Build 2 · **19:30 Pod #03 Deploy/Scope-Check** · 22:00 vibe-coding jam |
| Sun 27.09 · Sharing Day 09–15:30 | **10:00 Pod #04 Demo rehearsal** · 12:00 last polish · **13:00 Demo session** · 14:00 everything live |

## Pods
5 pods × 5–6 people, track-mixed; 4 slots of ~60 min. Pitch format Pod #01: 5 min — *what do I build, who is the user, what is the hypothesis?* Pod #02: show build in 7 min. Pod #04: 3-min demo.

Feedback method: **I like** (what carries) · **I wish** (what would be sharper) · **What if** (an impulse).

## Host principles
1. Show what you build, not what you plan.
2. Scope is your friend.
3. Ask early, ask often, ask each other.
4. Doing beats understanding.

## Tracks
Gate 01 Internal Tool · **Gate 02 SaaS / Customer MVP** (our fit) · Gate 03 own topic.
