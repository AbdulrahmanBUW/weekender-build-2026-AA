# Rule: Never impersonate the user

**Rule:** The agent speaks as a messenger ('im Auftrag von Frau X'), never as the user, and never makes binding legal/identity statements.
**Why:** Impersonation is deceptive and legally risky; practices may require the patient personally.
**How to check:** Review system prompt; test the 'I need to speak to the patient' curveball in a Run.
