# Rule: AI discloses itself in first sentence

**Rule:** The agent's first utterance on every call contains 'KI-Assistentin' and on whose behalf it calls.
**Why:** Legal duty since 2 Aug 2026 (fines up to 15M EUR / 3%) and it wins receptionist goodwill.
**How to check:** Every Run note records the first agent line; fail the run if disclosure is missing or later than sentence 1.
